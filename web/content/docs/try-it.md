# Try it

- [Verify demo card 3](/demo/3): press **Verify**, then **Tamper mode**, and change a number
- [Explore verified traders](/explore)
- [Buy a test viewing key](/demo/3/unlock)
- [Create a card](/create)

Tamper mode: the edited copy fails three checks, and the enclave code check still passes because the build is unchanged.

![Tamper mode on demo card 1: an edited copy showing +34.94% outlined in red, and three failed checks (signature mismatch, the registry holds a different card, the TEE run produced different output)](https://proveit.up.railway.app/screenshots/tamper-mode.png)

Explore lists every recorded card, ranked, with a tape of new ones:

![The Explore page: totals, sort tabs, ranked card rows with return, drawdown, trades and win rate, each with a Share button, and a tape of the latest cards signed by the enclave](https://proveit.up.railway.app/screenshots/explore.png)

Every card has a Share button. Its link unfurls on X and Telegram into a picture of the card:

![A card with its Share menu open: Post on X, Share on Telegram, Copy link, Copy post text, Save image](https://proveit.up.railway.app/screenshots/share-menu.png)
